# Traffic Alert Nepal

A community road-safety information platform for Nepal, starting with Kanchanpur and Kailali.

The platform is designed for public road conditions: congestion, crashes, closures, diversions, flooding and other hazards, plus verified official public advisories. It does not publish live police-officer positions or help people evade enforcement.

## Planned stack

- Next.js App Router + TypeScript
- Tailwind CSS
- Supabase (database, authentication and storage)
- OpenStreetMap with Leaflet
- Vercel deployment

## Development status

Initial repository setup. Application implementation is being added.

## Safety and moderation

Community submissions should remain pending until reviewed. Only approved, current road-safety reports should be shown publicly. Never post personal information or precise live locations of individual officers.
